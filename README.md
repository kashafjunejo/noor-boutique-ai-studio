# Noor Boutique

An AI-powered fashion boutique demo website built using Google AI Studio.

## Project Overview

Noor Boutique is a fashion shopping website prototype designed to help users explore clothing and receive AI-powered fashion suggestions.

## Features

- Responsive fashion boutique website
- Product browsing
- AI fashion assistant
- Fashion recommendations

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- Google AI Studio
- Google Cloud Run

## Live Demo

https://noor-boutique-style-that-feels-like-you-19381119086.asia-east1.run.app

## Project Status

This is a demonstration project developed for learning and hackathon purposes. Business and product information may be illustrative.

## Setup

Install dependencies using `npm install`, then run the development script specified in `package.json`.

## Security

API keys and other secrets should be stored securely and must not be committed to the public repository.
